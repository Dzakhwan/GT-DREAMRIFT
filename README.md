# GT-DREAMRIFT

**GT-DREAMRIFT** adalah sebuah game 3D bergenre Action-RPG/Adventure. Dalam game ini, pemain akan dibawa ke dalam sebuah petualangan seru untuk menjelajahi dunia, mengungkap cerita, dan bertarung melawan berbagai musuh.

## 📖 Sinopsis (Tentang Game)
*(Silakan tambahkan latar belakang cerita atau lore game Anda di sini. Contoh: "Di dunia Dreamrift, garis antara realitas dan mimpi mulai memudar. Pemain harus berpetualang untuk...")*

## 🎮 Mekanik Gameplay
Dalam **GT-DREAMRIFT**, pemain dapat melakukan berbagai aktivitas seperti:
- **Eksplorasi & Interaksi:** Menjelajahi dunia game dan berinteraksi dengan lingkungan sekitar, seperti membuka pintu rahasia atau memicu kejadian tertentu.
- **Sistem Pertarungan (Action Combat):** Menghadapi musuh dengan sistem pertarungan *real-time*. Pemain dapat melancarkan serangan kombo beruntun untuk mengalahkan berbagai tipe musuh (Mulai dari monster *melee*, *ranged*, hingga *Slime*).
- **Inventaris & Pengumpulan Item:** Mengumpulkan barang-barang atau *loot* yang tersebar di sepanjang permainan dan menyimpannya di dalam tas (Inventaris) untuk digunakan nanti.
- **Sistem Cerita & Dialog:** Mengikuti alur cerita yang imersif melalui sistem *cutscene* dan percakapan antar karakter.

## 🕹️ Kontrol Dasar
Game ini menggunakan kontrol keyboard dan mouse standar untuk game Action-RPG (menggunakan *Unity New Input System*).

- **W, A, S, D** : Menggerakkan Karakter
- **Klik Kiri (LMB)** : Menyerang musuh (Mendukung sistem *combo*)
- **E / F** : Berinteraksi dengan objek sekitar (Mengambil item, membuka pintu, dll)
- **Klik Kiri / Spasi** : Melanjutkan dialog saat *cutscene* berlangsung
*(Catatan: Anda dapat menyesuaikan deskripsi tombol ini sesuai dengan konfigurasi Input Actions di proyek)*

## ⚙️ Cara Menjalankan Proyek (Untuk Developer)
1. Pastikan Anda memiliki **Unity 3D** (Sebaiknya gunakan versi yang sama dengan saat pembuatan proyek).
2. *Clone* repositori ini atau unduh dalam bentuk ZIP.
3. Tambahkan proyek ini melalui **Unity Hub** dan buka.
4. Buka *Scene* utama, misalnya `MainMenu` atau `Level1` di dalam folder `Assets/Scenes`.
5. Tekan tombol **Play** di Unity Editor untuk mencoba game.
